# Visión

El Gabinete es un cuaderno local de numismática: pocas páginas, textos legibles y una forma directa de incorporar una pieza nueva.

## Para quién

Para quien quiera leer notas sobre monedas y billetes, y para quien ejecuta el proyecto y quiere publicar una nota sin configurar usuarios ni un servidor público.

## Qué problema resuelve el MVP

Permite enseñar y usar el recorrido completo de un blog pequeño: ver la lista, abrir un artículo y crear otro que permanece guardado en el equipo.

## Éxito

El MVP está conseguido cuando la portada, el detalle y el alta descritos en el PRD funcionan en local y los criterios de `acceptance_criteria.md` se cumplen.

## Principios

- El alcance escrito manda. Si cambia, primero se cambia la spec y después el código.
- Se construye solo lo que el PRD incluye.
- Los textos de la interfaz y de ejemplo están en español.
- La persistencia es un fichero local, fácil de inspeccionar.
